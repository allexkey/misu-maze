# 🍡 Misu Maze

A free, original maze-chase game that runs in the browser and installs on your phone as a PWA (works offline).
Two versions: **Venti** (full maze) and **Combo** (compact, ~40% size, bigger on phones). Munch every pearl, grab the big amber ones to scare the Grumps, and dodge them otherwise.

**▶ Play:** https://allexkey.github.io/misu-maze/

## Install on your phone
- **Android (Chrome):** open the link → menu ⋮ → *Install app* (or tap the in-game *Install app* button).
- **iPhone/iPad (Safari):** open the link → Share → *Add to Home Screen*.

## Controls
- Touch: swipe anywhere, or use the on-screen arrows.
- Keyboard: arrow keys / WASD · `P` or `Space` pause · `M` mute.

## Română
Joc gratuit, original, de tip labirint. Deschide linkul de mai sus și instalează-l pe telefon (Chrome → *Instalează aplicația*; Safari → *Partajează* → *Adaugă pe ecranul principal*). Funcționează și offline.

## Develop
No build step. Serve the folder with any static server (e.g. `python3 -m http.server`) and open it.
